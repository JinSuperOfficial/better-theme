## 约定

- 文件名全小写、kebab-case，不写版本号，中文名改英文。
- 复刻 / 案例类文档放 `cases/`。
- 文档里的交叉引用用相对路径，重命名时记得同步改。
- 用户明确指定的品牌色、风格、技术栈**优先于**本目录的任何建议。
