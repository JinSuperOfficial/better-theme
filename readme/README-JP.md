## はじめに

> ウェブフロントエンドに、独自の美学を持つデザイン案を生成する。ありきたりな SaaS テンプレート風を避けるために。
> An opinionated front-end design skill for AI agents.

AI Agent 向けのフロントエンドデザイン Skill です。配色、角丸、コピー、モーション、アクセシビリティを扱い、
「青紫グラデーション + 大きな角丸 + Hero の3カード + 中身のないコピー」という生成テンプレート病を専門に治します。

## 構成

```text
better-theme/
├── SKILL.md                      # 入口：デザイン総綱 + 実行フロー + 厳格モード
├── README.md                     # 簡体字中国語の説明（本ファイル）
├── readme/                       # その他の言語の説明
├── references/                   # 必要時に読み込むリファレンス文書（references/README.md 参照）
│   ├── README.md                 # 索引：どの状況でどれを読むか
│   ├── agent-guide.md            # 改善マニュアル：型判定 → 診断 → 修正 → チェックリスト
│   ├── color-theme.md            # 7 組のシーン別配色 + 色選択の決定木
│   ├── radius.md                 # macOS 風の角丸仕様（token / 同心ネスト / 連続曲率）
│   ├── copywriting.md            # UI コピーの参考（404 / 空状態 / ログイン / ローディング）
│   ├── interaction.md            # モーションとインタラクションの仕様（時間 / イージング / a11y / アンチパターン）
│   └── cases/
│       └── deepseek-glass.md     # 事例：グラスモーフィズム + WebGL 流体 + Spring アニメーション
├── asset/
│   └── icon/                     # 600+ のオフライン SVG アイコン（Alibaba アイコンライブラリを整理）
└── scripts/
    ├── check-refs.py             # ドキュメント衛生チェック（相互参照 / frontmatter / 改行コード / 行末の空白）
    └── sync-global.sh            # グローバル ~/.dsh/skills/better-theme へ同期
```

**読み込み方針**：`SKILL.md` が入口で、`references/` は必要に応じて読みます。現在のタスクに本当に必要なファイルだけを読み込んでください —— 配色だけのタスクで `interaction.md` を読む必要はありません。

## インストール

DSH Skill として使う場合は、リポジトリを skills ディレクトリに入れるだけです：

```bash
git clone https://github.com/JinSuperOfficial/better-theme.git ~/.dsh/skills/better-theme
```

`SKILL.md` の中身をそのまま会話に貼り付けて使うこともできます（Web 版 AI がローカルファイルを読めない場合）。
アイコン素材のオンライン閲覧：[asset/icon](https://github.com/JinSuperOfficial/better-theme/tree/main/asset/icon/)

## 3つの譲れない原則

1. **ユーザーの要求が優先**：ユーザーが指定したブランドカラー、スタイル、技術スタックは、本リポジトリのどんな提案よりも優先されます。
2. **アクセシビリティは譲らない**：コントラスト、キーボードフォーカス、`prefers-reduced-motion` の3項目は省略できません。
3. **テンプレートを作らない**：プロダクト名を差し替えても成立するなら、具体性が足りない証拠です。やり直してください。

## アンチパターン早見表

温かいクリーム色の背景 + セリフ体の見出し + テラコッタオレンジ / ほぼ黒の背景 + アシッドグリーン・朱色 / 細線ボーダー + 角丸ゼロ + 高密度なマルチカラム /
Hero + 3カード / ページ全体を機械的に中央揃え / すべてのコンポーネントを1つの大きな角丸で統一 —— どれか1つでも当てはまったら、即やり直しです。

## メンテナンス

ドキュメントを直したらチェックを1回実行し、相互参照が切れていないか、frontmatter が正しい YAML か、言語表が揃っているか、改行コードが統一されているかを確認します：

```bash
python3 scripts/check-refs.py
```

内容を変更してグローバルインストールを更新するときは、コマンド1つで同期します（`--dry-run` で先に何が変わるか確認できます）：

```bash
./scripts/sync-global.sh
```

## 規約

- ファイル名はすべて小文字の kebab-case。バージョン番号は書かず、中国語名は英語に変えます。
- 事例ドキュメントは `references/cases/` に置きます。
- ドキュメント間の相互参照は相対パスを使い、リネーム時は同時に更新します。
- 改行コードは一律 LF。
